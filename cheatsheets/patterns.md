# Patterns: Signal -> Pattern

Read the problem, spot the signal, pick the pattern. Numbers are LC problems in this repo's index.

## Arrays & Hashing
- **"Have I seen X before?" / pair summing to target, unsorted** -> Hashmap complement lookup (0001)
- **Duplicates / membership check** -> Hash set (0217)
- **Same letters, different order** -> Frequency count or sorted key (0242, 0049)
- **Top / most frequent k** -> Counting + bucket sort or heap (0347)
- **Product/sum of everything except i, no division** -> Prefix & suffix passes (0238)
- **Longest run of consecutive values, O(n)** -> Hash set, only start counting at run starts (0128)
- **One-to-one mapping between two sequences** -> Two maps, forward and reverse (0205, 0290)
- **Element appearing > n/2 times, O(1) space** -> Boyer-Moore voting (0169)
- **O(1) insert + delete + random pick** -> Hashmap value->index + array, swap with last on delete (0380)
- **Answer is a count bounded by n (h-index, frequency)** -> Bucket/counting sort capped at n (0274, 0347)
- **Valid Sudoku / grid groups** -> Seen-sets per row, col, box; box = (r/3)*3 + c/3 (0036)
- **Serialize a list of arbitrary strings** -> Length-prefix encoding "len#str" (0271)
- **Rotate array / reverse word order in place** -> Reverse all, then reverse the parts (0189, 0151)
- **Find a substring** -> Brute window; KMP (LPS array) for guaranteed O(n+m) (0028)
- **Roman numerals / formatting rules** -> Lookup table + greedy or look-ahead (0013, 0012)
- **Write text in a pattern / justify lines** -> Simulate rows or lines directly (0006, 0068)

## Two Pointers
- **Sorted array + pair/target** -> Two pointers converging (0167, 0015)
- **Palindrome check** -> Pointers from both ends (0125)
- **In-place remove/dedupe, O(1) space** -> Read/write pointers (0026, 0027)
- **Maximize area/water between bars** -> Converge, move the shorter side (0011, 0042)
- **Water trapped above each bar** -> min(maxLeft, maxRight) - h; two pointers move the smaller max (0042)
- **Merge into an array that has free space at the end** -> Fill from the back (0088)
- **Keep at most m copies in a sorted array** -> Read/write, compare with nums[k-m] (0026, 0080)
- **Is s a subsequence of t** -> One pointer per string, greedy match (0392)
- **Three/four numbers summing to target** -> Sort, fix one, two-pointer the rest, skip duplicates (0015)

## Sliding Window
- **Longest/shortest contiguous subarray/substring with a constraint** -> Variable window, grow right, shrink left (0003, 0076)
- **Fixed length k / anagram of pattern in string** -> Fixed window + counts (0567)
- **Max/min of every window of size k** -> Monotonic deque (0239)
- **Best buy-then-sell / best pair (i < j)** -> Running min of the prefix (0121)
- **Duplicate within distance k** -> Fixed window of a hash set (0219)
- **Shortest subarray with sum >= target, all positive** -> Grow right, shrink left while valid (0209)
- **Make window one letter with <= k changes** -> Valid iff len - maxFreq <= k (0424)
- **Smallest window containing all chars of t** -> Variable window + have/need counter (0076)
- **Concatenation of equal-length words** -> Token window, one pass per offset (0030)

## Stack
- **Matching brackets / nested structure** -> Stack (0020)
- **Next greater/smaller element** -> Monotonic stack (0739, 0084)
- **Evaluate expression / undo last thing** -> Operand stack (0150, 0224)
- **Aggregate (min/max) that must survive pops** -> Stack of (value, aggregate so far) (0155)
- **Generate all balanced strings** -> Backtracking with open/close counts (0022)
- **Largest rectangle / span bounded by shorter bars** -> Increasing stack: pop gives next smaller, new top gives previous smaller (0084)
- **Infix with + - and parens** -> Running result + sign, stack of (result, sign) per "(" (0224)
- **Path with "." and ".."** -> Split + stack of names (0071)
- **Things that catch up and merge (fleets)** -> Sort by position, compare arrival times to the one ahead (0853)

## Binary Search
- **Sorted input, find target/boundary** -> Binary search / lower bound (0704, 0035)
- **"Minimum X such that condition holds", monotonic feasibility** -> Binary search on the answer (0875)
- **Rotated sorted array** -> Find which half is sorted (0033, 0153)
- **First / last occurrence, insert position** -> Lower bound; last = lowerBound(x+1) - 1 (0035, 0034)
- **Integer sqrt / "largest k with f(k) ≤ x"** -> Binary search on k, record and go right (0069)
- **Sorted matrix where rows chain together** -> Flat index k -> (k / cols, k % cols) (0074)
- **Unsorted but "any local peak"** -> Compare mid with mid+1, go uphill (0162)
- **Versions per key, "latest at or before t"** -> Hashmap of sorted lists + upper bound - 1 (0981)
- **Median / kth of two sorted arrays in log time** -> Binary search the partition of the shorter array (0004)

## Linked List
- **Cycle / middle / nth from end** -> Fast & slow pointers (0141, 0019)
- **Head may change** -> Dummy node (0021, 0082)
- **Reverse all or part of a list** -> Iterative prev/curr/next (0206, 0092)
- **O(1) get/put with eviction order** -> Hashmap + doubly linked list (0146)
- **Merge sorted lists** -> Dummy + tail (0021); k lists: min-heap of heads or pairwise merge (0023)
- **Interleave front and back of a list** -> Find mid + reverse second half + weave (0143)
- **Reverse in groups / a sub-range** -> Check k exist, reverse with prev = groupNext, reconnect (0025); head insertion (0092)
- **Deep copy with extra pointers** -> Map old -> new in two passes, or interleave copies (0138)
- **Values in [1, n], find the repeat, O(1) space** -> Floyd on i -> nums[i] (0287)
- **Rotate list by k** -> k mod n, close ring, cut at n - k (0061)
- **Stable partition / remove runs** -> Two dummy chains (0086); dummy + skip whole run (0082)
- **Sort a linked list** -> Merge sort; split with fast = head.next (0148)
- **Big numbers as digit lists** -> Digit-wise add with carry, loop while l1 or l2 or carry (0002)

## Trees
- **Depth / height / path property** -> DFS returning a value up, global for the answer (0104, 0124)
- **Level by level / right side view** -> BFS with queue size per level (0102, 0199)
- **BST + sorted order / kth** -> Inorder traversal (0230)
- **Validate BST** -> DFS with (low, high) bounds (0098)
- **Mirror / identical / contains a subtree** -> Parallel DFS on two trees (0100, 0101, 0572)
- **Best path anywhere (diameter, max path sum)** -> Return one branch up, record the bent path in a global (0543, 0124)
- **Balanced check** -> Bottom-up height with -1 for "unbalanced" (0110)
- **Condition on the root-to-node path** -> Pass state down: path max, remaining sum, number so far (1448, 0112, 0129)
- **LCA in a BST** -> Walk down until p and q split (0235); general tree -> postorder "found" returns (0236)
- **Rebuild from two traversals** -> Preorder/postorder give roots, inorder index map gives the split (0105, 0106)
- **Serialize a tree** -> Preorder with null markers (0297)
- **Iterate a BST lazily** -> Stack of the pending left spine (0173)
- **Flatten / link levels in O(1) space** -> Splice rightmost of left subtree (0114); walk levels via next + dummy (0117)
- **Count nodes of a complete tree fast** -> Equal spine heights mean 2^h - 1 (0222)
- **Sorted array to balanced BST / quad tree** -> Divide at the middle / into quadrants (0108, 0427)

## Tries
- **Prefix queries / many words against one grid or stream** -> Trie (0208, 0212)
- **Dictionary search with '.' wildcards** -> Trie + DFS branching only on '.' (0211)
- **Find many words on a grid** -> Trie of words + one backtracking DFS per cell, prune found branches (0212)

## Heap / Priority Queue
- **Kth largest/smallest, top k** -> Heap of size k (0215, 0973)
- **Running median** -> Two heaps (0295)
- **Merge k sorted things** -> Min-heap of heads (0023)
- **k-th largest in a stream / k largest overall** -> Min-heap of size k (0703, 0215); quickselect for one-off arrays (0215)
- **k closest / k smallest by a key** -> Max-heap of size k (0973)
- **Repeatedly take the largest and put back a remainder** -> Max-heap simulation (1046)
- **Same item needs a cooldown** -> Count formula from the most frequent item, or heap + cooldown queue (0621)
- **Latest 10 across many timelines** -> Heap merge of per-user lists (0355)
- **Greedy best affordable option as budget grows** -> Sort by requirement + max-heap (0502)
- **k smallest pair sums from two sorted arrays** -> Heap frontier over rows (0373)

## Backtracking
- **All subsets / permutations / combinations** -> Backtracking with choose/explore/unchoose (0078, 0046, 0039)
- **Input has duplicates, unique results** -> Sort + skip `i > start && a[i] == a[i-1]` (0090, 0040)
- **Each digit/position picks from its own option list** -> One recursion level per position (0017)
- **Target sum, unlimited reuse** -> Sorted loop from start, recurse with `i`, break on overshoot (0039)
- **Choose exactly k of 1..n** -> Start index + "enough left" prune `i <= n - need + 1` (0077)
- **Order matters (arrangements)** -> Loop over all indices with `used[]` (0046)
- **Trace a word through adjacent grid cells** -> DFS with in-place mark/unmark (0079)
- **Split a string into valid pieces** -> Backtrack over the next cut end (0131)
- **Place items with row/col/diagonal conflicts** -> Row-by-row + sets for c, r-c, r+c (or bitmasks) (0051, 0052)

## Graphs
- **Grid of islands / connected regions** -> DFS/BFS flood fill (0200)
- **Shortest path, unweighted** -> BFS (0127)
- **Spreads from many sources at once** -> Multi-source BFS (0994)
- **Prerequisites / ordering / cycle in directed graph** -> Topological sort (Kahn's) (0207, 0210)
- **Dynamic connectivity / redundant edge** -> Union-Find (0684)
- **Size of the largest region** -> Flood fill returning `1 + sum(neighbours)` (0695)
- **Regions that touch / reach the border** -> Flood fill *from* the border, then sweep (0130, 0417)
- **Cells that can reach two targets** -> Reverse search from each target, intersect (0417)
- **Distance to nearest of many sources** -> Multi-source BFS, first visit wins (0286, 0994)
- **Deep-copy a graph with cycles** -> DFS/BFS with old → new map as visited (0133)
- **Is this undirected graph a tree?** -> Exactly n - 1 edges + no failed union (0261)
- **Count components from an edge list** -> Union-Find: start at n, decrement per successful union (0323)
- **Ratios / a/b = k relations** -> Weighted edges, multiply along a path; or weighted Union-Find (0399)
- **Fewest single-letter changes between strings** -> BFS; neighbours by substitution or wildcard buckets (0433, 0127)
- **Board game with jumps, fewest moves** -> Flatten board to 1-D, BFS on squares (0909)

## Advanced Graphs
- **Shortest path, non-negative weights** -> Dijkstra (0743)
- **Connect all points with min total cost** -> MST, Prim's or Kruskal's (1584)
- **Shortest path with at most k edges** -> Bellman-Ford, k+1 rounds (0787)
- **Path cost = max cell/edge on the path** -> Dijkstra with max instead of +, or binary search + flood fill (0778)
- **Use every edge exactly once / itinerary** -> Hierholzer post-order DFS, reverse at the end (0332)
- **Order hidden in sorted words** -> First differing letter of adjacent pairs = edge, then topo sort (0269)

## 1-D DP
- **Count ways / min cost to reach step i** -> dp[i] from dp[i-1], dp[i-2] (0070, 0746)
- **Pick non-adjacent items** -> Take/skip DP (0198)
- **Min coins / can amount be formed** -> Unbounded knapsack (0322)
- **Can string be split into dictionary words** -> Prefix DP (0139)
- **Count ways to decode / segment with rules** -> dp[i] adds dp[i-1], dp[i-2] only when the step is valid (0091)
- **Circular non-adjacent picks** -> Two linear passes: skip first / skip last (0213)
- **Max product subarray** -> Track max and min ending here (0152)
- **Longest increasing subsequence** -> tails + binary search, O(n log n) (0300)
- **Split into two equal-sum halves / exact subset sum** -> 0/1 knapsack, sweep sums backwards (0416)
- **Longest / count palindromic substrings** -> Expand around 2n-1 centers (0005, 0647)

## 2-D DP
- **Two strings, compare/align** -> dp[i][j] over prefixes (1143, 0072)
- **Can s3 be a merge of s1 and s2** -> dp[i][j] over prefixes, s3 index = i + j (0097)
- **Count ways t appears as a subsequence of s** -> Prefix DP, skip or use s[i-1], dp[i][0] = 1 (0115)
- **Pattern with `.` and `*`** -> Memo on (i, j), look ahead for `*`: skip pair or eat one char (0010)
- **Paths in a grid, right/down moves** -> Grid DP from top + left, one rolling row (0062, 0063, 0064)
- **Triangle / pyramid min path** -> Fold bottom-up so every cell has two children (0120)
- **Largest all-1 square** -> dp = 1 + min(top, left, diag) (0221)
- **Buy/sell with states (cooldown, k txns)** -> State machine DP (0309, 0123, 0188)
- **Count coin combinations (order doesn't matter)** -> Unbounded knapsack, coins outer loop (0518)
- **± signs to hit a target** -> Count subsets summing to (total + target) / 2 (0494)
- **Burst / merge where cost uses current neighbours** -> Interval DP, choose the LAST one in (l, r) (0312)
- **Longest strictly increasing path in a grid** -> DFS + memo; increasing means DAG, no visited set (0329)

## Greedy
- **Max subarray sum** -> Kadane (0053)
- **Max subarray on a circular array** -> max(Kadane max, total - Kadane min); all-negative -> max element (0918)
- **Can reach end / min jumps** -> Track farthest reach; BFS levels without a queue (0055, 0045)
- **Circular route with gains and costs** -> Total >= 0 check, reset start when the tank goes negative (0134)
- **Split into groups of k consecutive values** -> Sorted counts; smallest remaining value starts groups (0846)
- **Reach a target with element-wise max merges** -> Drop anything that overshoots, then check each coordinate is hit (1899)
- **Max pieces with each letter in one piece** -> Last occurrence + extend window end, cut at i == end (0763)
- **Wildcards with several meanings (`*` = ( ) or empty)** -> Track [lo, hi] range of open counts (0678)
- **Unlimited stock trades** -> Sum every positive day-to-day change (0122)
- **Constraints toward both neighbours** -> Left pass + right pass, combine with max (0135)

## Intervals
- **Overlapping intervals** -> Sort by start, merge (0056)
- **Insert into a sorted disjoint list** -> Three phases: before / overlap (widen) / after, O(n) (0057)
- **Can one person attend all meetings** -> Sort by start, compare neighbours (0252)
- **Max non-overlapping / min removals / min arrows** -> Sort by end, greedy (0435, 0452)
- **Max concurrent intervals (rooms)** -> Sorted starts & ends, or min-heap of ends (0253)
- **Smallest interval containing each query** -> Sort queries offline, sweep + min-heap by size, lazy pop (1851)
- **Sorted distinct ints into ranges** -> Scan while next == cur + 1 (watch INT_MAX + 1) (0228)

## Math & Geometry
- **Integer palindrome, no strings** -> Reverse half; reject negatives and trailing zeros (0009)
- **Number stored as digits/strings (+1, multiply)** -> Right-to-left carry; product digit i*j lands at i+j, i+j+1 (0066, 0043)
- **Repeated digit transform, does it end?** -> Cycle detection: seen-set or Floyd (0202)
- **x^n, huge n** -> Exponentiation by squaring; widen n before negating (0050)
- **Trailing zeros of n!** -> Sum n/5 + n/25 + ... (0172)
- **Rotate matrix in place** -> Transpose + reverse each row (0048)
- **Spiral traversal** -> Four shrinking bounds, guard the last two sides (0054)
- **In-place matrix update needing old values** -> Flags in row 0 / col 0, or next state in bit 1 (0073, 0289)
- **Count axis-aligned squares with a query point** -> Point counts, iterate diagonal corners (2013)
- **Most collinear points** -> Anchor + gcd-reduced, sign-normalised slope map (0149)

## Bit Manipulation
- **Every element twice except one** -> XOR all (0136)
- **Every element three times except one** -> Count each bit mod 3 (0137)
- **Missing number in 0..n** -> XOR indices and values (or Gauss sum) (0268)
- **Count/clear lowest set bit** -> `n & (n-1)` (0191)
- **Bit counts for all 0..n** -> ans[i] = ans[i >> 1] + (i & 1) (0338)
- **Reverse a fixed-width bit pattern** -> Pop low bit, push onto result, exactly 32 times (0190)
- **Add without + / -** -> XOR = sum without carry, (a & b) << 1 = carry; mask in Python (0371)
- **Add numbers given as strings** -> Right-to-left with carry, loop while carry remains (0067)
- **Reverse digits with 32-bit overflow** -> Check r against INT_MAX / 10 before pushing (0007)
- **AND of a whole range** -> Common binary prefix of left and right (0201)
